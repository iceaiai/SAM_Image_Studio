# Original supplied files

All five user-supplied files are stored byte-for-byte in `uploads/` and included
as downloadable artifacts in the built documentation:

- {download}`SAM_Image_Studio_v1.4.2_CPU.zip <../../uploads/SAM_Image_Studio_v1.4.2_CPU.zip>`
- {download}`SAM_Image_Studio_User_Manual.pdf <../../uploads/SAM_Image_Studio_User_Manual.pdf>`
- {download}`SAM_Image_Studio_For_Developer.pdf <../../uploads/SAM_Image_Studio_For_Developer.pdf>`
- {download}`SAM_Image_Studio_Denoising_Parameters.pdf <../../uploads/SAM_Image_Studio_Denoising_Parameters.pdf>`
- {download}`3PM_Compressed_Sensing.ipynb <../../uploads/3PM_Compressed_Sensing.ipynb>`

The source archive is also extracted into the repository root so the
application, installers, examples, and tests can be edited directly.

The archive includes earlier packaged PDF resources in `docs/` and
`samstudio/resources/`. They differ from the separately supplied PDFs above;
both are preserved. Sphinx includes the editable Markdown manuals from the
archive, augmented by source-based installation and development pages.
