1.4.2 — original

Download ZIP · SHA-256

Original, unchanged CPU source archive

Open its inner SAM_Image_Studio folder; Windows: Install_CPU.bat, then Start_GUI.bat; Linux: bash install_cpu.sh, then bash start_gui.sh. Its earlier installers do not include the v1.4.3 repairs.

These are the CPU application archives currently available in this repository. The table does not advertise unprovided older versions or standalone executables. Both source packages need 64-bit Python 3.12 and an installation step after extraction. Model weights are separate, on-demand downloads.

The v1.4.3 archive contains the full shared application, including GPU/, and can be used with either the CPU installer or its optional GPU installer. Follow the common download/clone step before choosing any CPU/GPU installation route. If you use Git instead, run the clone commands once; do not both clone and download unless you want two copies.

Which CPU package should I choose?#

Use 1.4.3 for new installations. It adds public SAM3 ONNX text segmentation, current UI/docs, automatic Ubuntu/WSL Qt dependency repairs and reorganized helpers. CPU also supports SAM1 and SAM2/2.1. Native SAM3/SAM3.1 require the separate GPU installation route; they are not CPU model options.

The 1.4.2 ZIP remains available for reproducing the original release. Its folder layout and installation instructions differ. Use its own included manuals rather than running v1.4.3 helper paths inside that archive.
