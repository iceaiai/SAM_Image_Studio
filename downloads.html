Follow the README and installer included in the chosen ZIP. Verify the supplied 1.0–1.4.1 CPU ZIPs using the SHA-256 checksums.

Every source package needs installation after extraction. The current CPU helpers automatically use or prepare 64-bit Python 3.12 on Windows/Linux x86-64. Versions 1.4.2 and 1.4.3 require Python 3.12 beforehand. Model weights in the standard edition download on demand. Prepare the offline cache online before transferring the extracted offline edition. See the offline installation guide.

The standard archive contains the full shared application, including GPU/, and can be used with either the CPU installer or its optional GPU installer. Follow the common download/clone step before choosing any CPU/GPU installation route. If you use Git instead, run the clone commands once; do not both clone and download unless you want two copies.

Which CPU package should I choose?#

Use 1.4.5.2 for connected installations or prepare 1.4.5.2 offline CPU for a disconnected installation. The standard edition also includes public SAM3 ONNX text segmentation. CPU also supports SAM1 and SAM2/2.1. Native SAM3/SAM3.1 require the separate GPU installation route; they are not CPU model options.

For 1.4.2, open the inner SAM_Image_Studio folder. On Windows, run Install_CPU.bat, then Start_GUI.bat. On Linux, run bash install_cpu.sh, then bash start_gui.sh. See the manuals bundled with that ZIP.
