samstudio.inference.initialize_torch_runtime()#

Initialize native CPU thread pools once, before Qt starts model workers.

Reconfiguring PyTorch’s process-wide OpenMP pool from a QRunnable can crash a cold process in torchvision’s first contiguous tensor conversion. Model construction/embedding/prediction still run in the background worker.
