Workspace and panels#

Area

Purpose and use

Central canvas

Display the current image, masks/contours, draft shapes, prompts, previews, and selections. Mouse wheel zooms; Hand or middle drag pans; F fits the image.

Objects, upper right

Select one/many annotations; canvas/list selections stay synchronized. Columns show Object, Group, Area, Lock. Visibility/lock controls govern display and editing eligibility. Double-click enters object editing.

Groups, right

Show labels and counts. + Group creates a label, Rename changes it, Color changes its color. Double-click selects its objects; choose the active drawing group in the top toolbar.

Image files, lower right

Choose source images, datasets, or stack frames. Multi-select to remove session entries using Remove selected images while retaining saved annotations and sources.

Workflow toolbar

Choose Mode, model, active Group, and Scope; run, accept, cancel, or configure inference.

Segmentation prompts toolbar

Type/run text, manage aliases, and choose positive/negative shape polarity.

Drawing tools, left

Select/pan, undo/redo, edit/delete, and draw polygon/rectangle/circle/ellipse/point.

Region tools

Select all, invert, create an object from a region, and reach appearance/transformation tools.

Status bar

Shows progress, filtered-mask counts, errors, save state, and zoom. Model loading and processing run as background jobs.

Docks can be resized or hidden. Reopen Objects, Groups, or Image files through View. This release retains the v1.4 Objects/Groups/Image files layout.

The screenshot uses the bundled synthetic image and manually supplied reference masks. It demonstrates panels and calibration, not model accuracy.

At startup, Reopen previous images? offers Yes or No. No opens an empty workspace without deleting saved projects. Removing an image saves it first; a failed save blocks removal so the user can select a writable destination.
