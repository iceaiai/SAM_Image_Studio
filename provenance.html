Sources, versions, and licenses#

This documentation is based on the supplied SAM Image Studio 1.4.2 CPU archive, its application source and editable manuals, the three separately uploaded PDF manuals, and the compressed-sensing teaching notebook. The PDFs identify an English edition dated October 22, 2026.

The original uploads are retained unchanged under uploads/. uploads/SHA256SUMS records their SHA-256 digests. Source code, installers, tests, bundled wheels, packaged PDFs, and historical validation files were extracted from the ZIP. The repository README and Sphinx/CI configuration are new repository documentation. Version 1.4.3 adds the SAM3 ONNX adapter, model-manager token entry, installation repairs and repository organization. Version 1.4.4 adds the classical watershed, signal-scaled noise, per-image input state, automatic Python preparation and restricted offline CPU distribution. Current code/requirements therefore differ from the original archive.

uploads/FILE_MANIFEST_SHA256_v142.json is the original release archive manifest. Its paths refer to files in that archive, including the original README, not to the newly authored repository README or other documentation additions. Verify it against the ZIP’s SAM_Image_Studio/ contents. It is not a manifest of the current Git checkout.

Historical reports in docs/archive/TEST_REPORT_v142.md and docs/validation/ retain their original scope and claims. A Sphinx build validates documentation generation. It does not rerun those application tests or prove model accuracy, CUDA compatibility, or native Windows execution. See the development page for current validation commands and the missing external-asset manifest limitation.

The application source includes an MIT license. Third-party model/dependency licenses and notices are separate; see third_party/NOTICE.md and the supplied SAM licenses. BM3D/bm4d have upstream academic/non-commercial terms. Review the applicable terms for each backend and checkpoint. The app license does not automatically relicense the supplied notebook, workshop assets, model weights, or third-party packages.

Figure provenance#

Workflow figures use public synthetic particles generated by docs/tools/generate_workflow_figures.py. Scope outlines are manual reference-mask schematics. Cleaning and DCT/TV figures execute the application’s actual algorithms. The SAM3 ONNX screenshot uses genuine CPU inference on the bundled synthetic image. The 1.4.4 EMD/TIFF originals were explicitly supplied for public examples. Their ONNX screenshots show actual CPU inference; noise/watershed comparisons run the application algorithms on those files. They are not ground-truth masks or native SAM3.1 GPU predictions. Their source data is not automatically relicensed by the application MIT license. Raw GUI screenshots contain no credentials. The five inline chat images are not included without their original source files.

Public ONNX adapter#

The six export files come from the public X-AnyLabeling v3.0.0 release, with pinned SHA-256 digests in samstudio/sam3_onnx.py. Application integration was implemented independently; GPL application code is not vendored. The CLIP tokenizer source has its original MIT notice and a separate third_party/CLIP_LICENSE.txt; its vocabulary is downloaded and verified separately. Checkpoint redistribution and use remain subject to the upstream SAM license.
